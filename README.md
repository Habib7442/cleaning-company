# Lustra — Premium Cleaning Website

A premium, design-led boutique cleaning service website for considered spaces.

## Tech Stack
- **Core:** HTML5, Vanilla JavaScript (Vite)
- **Styling:** Vanilla CSS (Modern Fluid Design System, CSS Grid)
- **Interactivity:** Squeegee Before/After comparison slider, Dynamic Pricing calculator, Infinite City Ticker Marquee, and a Multi-step Booking Stepper Flow with LocalStorage state recovery
- **Animation:** Lenis Smooth Scroll, Intersection Observer CSS Reveal Animations

## Key Features
- **Responsive Navigation:** Clean mobile drawer overlay and optimized desktop layout.
- **Interactive Squeegee Slider:** Drag, touch, or click to move slider handle with custom inertia (lerp-based spring physics).
- **Responsive Multi-step Quote:** Estimates flat-rate prices in real time based on space size and visit frequency.
- **SEO & Social Previews:** Configured title/description tags and Open Graph meta previews.
